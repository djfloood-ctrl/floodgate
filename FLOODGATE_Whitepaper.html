What Is FLOODGATE?

FLOODGATE is a short-form content generation engine that transforms raw video, audio, and AI voiceover assets into randomized, formatted, captioned clips — optimized for Instagram Reels, TikTok, YouTube Shorts, and every major platform in between.

It addresses a practical problem for creators and marketing teams: short-form platforms reward frequent posting, and editing each clip by hand does not scale. FLOODGATE turns one library of source material into a large batch of distinct clips. Each render draws different source clips, timestamps, music excerpts and voiceovers, and runs unattended once started.

Core Capabilities

The application is organized into three workspaces (Assets, Browse and Upload), supported by a standalone rendering engine.

Contrast Engine

Dual-act clip pairing — Sad (Act A) vs. Energy (Act B) — with independent music beds, burned-in captions, and a branded logo outro timed to a voiceover clip.

Format Presets

12 built-in presets covering every major platform: Reel/TikTok (1080×1920), YouTube Shorts, Instagram Story, Snapchat, Square (1:1), LinkedIn, Widescreen (16:9), Twitter/X, Facebook, Cinematic (21:9), Pinterest (2:3), and Custom dimensions with user-defined width, height, and FPS. User-defined format and length presets persist in config.json.

Template System

Switch between render templates — SAD CLIP / HAPPY CLIP for contrast content, LONGFORM CLIPS for podcasts and extended source material. Custom templates can be created and removed; default templates are protected. The remixer currently renders the SAD CLIP / HAPPY CLIP structure only; LONGFORM rendering is planned.

Asset Management

Six dedicated asset slots (Act A video, Act B video, Act A music, Act B music, voiceovers, longform source) plus a separate logo slot. Files under 200MB are auto-copied to organized subfolders. Large files reference in place. Delete and backspace remove selections instantly.

Smart Browse Gallery

4-card-per-row gallery view of rendered output. Sort by date (newest first), favorites first, or name A-Z. Filter by folder or tag with zero page reloads — all filtering happens in-place on existing cards. Live search filters instantly as you type.

Favorites & Tags

Star any clip to mark it as a favorite — toggles instantly with no UI rebuild. Add color-coded tags from a 6-color palette. Up to 3 tags visible per card. Tags and favorites survive sessions via persistent JSON metadata.

Folder System

Organize clips into custom folders. Create new folders on the fly from the sidebar. Move clips between folders without leaving the browse view. Folder labels update in-place on the card immediately after assignment.

Trash System

Instant trash with one click — the card vanishes from the gallery immediately with no delay. Restore clips back to output with one click. Permanent delete requires confirmation. Empty Trash wipes the entire trash directory at once.

Live Remixer Log

Remixer output streams line by line into a log panel on the Assets tab. When the render finishes, the status bar reports success or the exit code, and the Browse gallery refreshes automatically.

Project Bins

Save and load full artist profiles with independent asset pools, caption settings, format presets, render counts, and template selections. Switch projects from the top bar without losing any configuration. Default project is always available.

Render Control

Slider + quick-select buttons (5, 10, 25, 50, 100) to set render count. Ctrl+R launches the remixer from anywhere in the app. Renders run in a background process so the UI remains responsive, and a second render cannot be started while one is in progress.

Automatic Subtitles

Transcribes any video or audio file, including full podcasts and interviews, locally with Whisper, and burns in styled captions: Pop, with the spoken word highlighted, or Classic bottom-line captions. It also writes an .srt file. Transcripts are cached per file, so later excerpts reuse them instantly.

Upload Queue (Planned)

Rendered clips can be queued for Instagram and TikTok from the Browse view. Platform pairing and publishing are not yet connected to either service; the queue currently serves as a staging list.

Technical Architecture

Rendering Pipeline

The UI and the renderer run as separate processes. Starting a render saves the current settings to config.json and launches remixer.py via subprocess.Popen with unbuffered output. A background thread reads the process output and forwards each line to the log panel on the UI thread, so the interface stays responsive regardless of batch size. On exit, the return code is reported and the gallery refreshes.

Within each render, every source is first normalized to an identical specification (target resolution and frame rate, H.264 / yuv420p video, AAC stereo 44.1 kHz audio). Captions are then burned in, music is mixed under each act, and a logo outro is generated to match the voiceover's duration. Because all segments share one specification, the final concatenation is reliable. Source clips shorter than the requested duration are avoided, and clips that fail to decode are retried with a different source.

In-Place Filtering Architecture

The browse gallery does not rebuild from scratch on every filter action. Each card widget is tracked in a _card_widgets dictionary keyed by filename. Folder changes, tag filters, and search queries show/hide existing cards using pack() and pack_forget() rather than destroying and recreating the DOM. This means filtering is instant regardless of library size. A full rebuild happens only when explicitly requested through the refresh button or a sort change.

Metadata & Persistence

All clip metadata (favorites, tags, folders, view counts) is stored in clip_meta.json. On startup, the ClipMeta class scans both the output and trash directories and migrates any untracked files into the metadata store automatically. Project configurations are stored as individual project.json files inside projects/[name]/ directories. Global settings persist to config.json and are written on every change. Each project stores an independent copy of its settings, so switching projects never carries values from one project to another.

Momentum Scrolling

A custom global scroll handler tracks time between scroll events and builds momentum on consecutive fast scrolls (up to 4x multiplier). Momentum decays when scroll events slow down. The handler correctly routes scroll events to whichever scrollable frame is currently visible — the browse gallery, the assets panel, or individual listboxes.

File Handling

Files under 200MB are copied to their designated asset subfolders on import. Files over 200MB are referenced by absolute path to avoid unnecessary disk duplication. All paths are stored with forward slashes and resolved relative to the application folder. Assets that are missing on disk are flagged in the list rather than interrupting startup. The logo slot supports PNG and JPG.

Business Applications

Music & DJs
Generate hundreds of promotional clips from a single music video, live set, or studio session. Each clip features a different section of the track, different visual moments, and branded captions ready for Reels, TikTok, and Stories. The two-act structure was designed for this use case: Act A sets up the contrast, and Act B delivers the track.
Content Agencies
Scale short-form production from dozens to thousands of clips per client per month. Template-based rendering ensures brand consistency across all output. Project Bins let you maintain fully isolated configurations for every client with one-click switching.
Podcasts
Once longform rendering is available, the Longform Clips template will extract highlight clips from full episodes and pair them with branded visuals and voiceovers.
Sports Media
Clip goal reactions, highlight plays, and post-game moments in batches. Output to every required format (vertical, square, widescreen) from a single source file in one render pass.
Comedy & Entertainment
Turn specials, sets, and sketch packages into hundreds of shareable clips. Random timestamp selection gives each clip different material rather than a fixed highlight reel.
Real Estate & Commercial
Generate property walkthrough clips, product showcases, and testimonial snippets in bulk with consistent branding, logo watermarks, and captions locked per project.
