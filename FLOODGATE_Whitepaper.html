What Is FLOODGATE?

The algorithm doesn't care how tired you are. It wants content today, tomorrow, and the day after that. FLOODGATE is my answer to that. One session of footage turns into hundreds of clips — automated, randomized, ready to post. I built this because I needed it, and now it works.

FLOODGATE is a short-form content generation engine that transforms raw video, audio, and AI voiceover assets into randomized, formatted, captioned clips — optimized for Instagram Reels, TikTok, YouTube Shorts, and every major platform in between.

It combines a YEEZY-inspired brutalist design aesthetic with production-grade FFmpeg rendering to solve the fundamental problem facing every creator: volume. The algorithm demands constant output. FLOODGATE turns one batch of source material into hundreds of unique clips — each with different timestamps, different music pairings, random voiceover combinations. No two renders are identical. What would take hours of manual editing takes minutes of automated rendering.

Core Capabilities

FLOODGATE is a modular workspace. Every component is independent, configurable, and built to be fast. Here's what's under the hood:

Contrast Engine

Dual-act clip pairing — Sad (Act A) vs. Energy (Act B) — with independent music beds and AI voiceover channels. The signature FLOODGATE format that makes every render feel intentional.

Format Presets

12 built-in presets covering every major platform: Reel/TikTok (1080×1920), YouTube Shorts, Instagram Story, Snapchat, Square (1:1), LinkedIn, Widescreen (16:9), Twitter/X, Facebook, Cinematic (21:9), Pinterest (2:3), and fully Custom dimensions with user-defined width, height, and FPS.

Template System

Switch between render templates — SAD CLIP / HAPPY CLIP for contrast content, LONGFORM CLIPS for podcasts and extended source material. Custom templates can be created, saved, and archived. Default templates are protected.

Asset Management

Six dedicated asset slots (Act A video, Act B video, Act A music, Act B music, voiceovers, longform source) plus a separate logo slot. Files under 200MB are auto-copied to organized subfolders. Large files reference in place. Delete and backspace remove selections instantly.

Smart Browse Gallery

4-card-per-row gallery view of rendered output. Sort by date (newest first), favorites first, or name A-Z. Filter by folder or tag with zero page reloads — all filtering happens in-place on existing cards. Live search filters instantly as you type.

Favorites & Tags

Star any clip to mark it as a favorite — toggles instantly with no UI rebuild. Add color-coded tags from a 6-color palette. Up to 3 tags visible per card. Tags and favorites survive sessions via persistent JSON metadata.

Folder System

Organize clips into custom folders. Create new folders on the fly from the sidebar. Move clips between folders without leaving the browse view. Folder labels update in-place on the card immediately after assignment.

Trash System

Instant trash with one click — the card vanishes from the gallery immediately with no delay. Restore clips back to output with one click. Permanent delete requires confirmation. Empty Trash wipes the entire trash directory at once.

Live Render Polling

Browse gallery auto-updates while the remixer is rendering in a separate terminal. Polls the output directory every 1.5 seconds and adds new clips as they appear. Auto-stops polling when the render completes and cleans up the signal file.

Project Bins

Save and load full artist profiles with independent asset pools, caption settings, format presets, render counts, and template selections. Switch projects from the top bar without losing any configuration. Default project is always available.

Render Control

Slider + quick-select buttons (5, 10, 25, 50, 100) to set render count. Preview Mode option. Ctrl+R keyboard shortcut launches the remixer from anywhere in the app. Renders run in a separate terminal window so the UI stays live during processing.

Upload Queue

Queue rendered clips for Instagram and TikTok directly from the browse view. Attach captions per clip. Pair platform accounts once. Upload all queued drafts in one action. Remove individual drafts from the queue before posting.

Technical Architecture

Rendering Pipeline

FLOODGATE separates the UI process from the render process entirely. When you hit RUN, it writes a _run_remixer.bat script and launches it in a new terminal window via subprocess.Popen with CREATE_NEW_CONSOLE. This means the UI never freezes during a render, no matter how many clips are queued. When the render completes, the bat script drops a _render_complete.txt signal file that the live polling loop detects — polling stops, the gallery refreshes, and the signal file is cleaned up automatically.

In-Place Filtering Architecture

The browse gallery does not rebuild from scratch on every filter action. Each card widget is tracked in a _card_widgets dictionary keyed by filename. Folder changes, tag filters, and search queries show/hide existing cards using pack() and pack_forget() rather than destroying and recreating the DOM. This means filtering is instant regardless of library size. A full rebuild only happens when explicitly requested via the refresh button or a sort change.

Metadata & Persistence

All clip metadata (favorites, tags, folders, view counts) is stored in clip_meta.json. On startup, the ClipMeta class scans both the output and trash directories and migrates any untracked files into the metadata store automatically. Project configurations are stored as individual project.json files inside projects/[name]/ directories. Global settings persist to config.json and are written on every change.

Momentum Scrolling

A custom global scroll handler tracks time between scroll events and builds momentum on consecutive fast scrolls (up to 4x multiplier). Momentum decays when scroll events slow down. The handler correctly routes scroll events to whichever scrollable frame is currently visible — the browse gallery, the assets panel, or individual listboxes.

File Handling

Files under 200MB are copied to their designated asset subfolders on import. Files over 200MB are referenced by absolute path to avoid unnecessary disk duplication. All paths are stored with forward slashes for cross-platform consistency. The logo slot supports PNG and JPG with a separate preview-ready asset folder.

Business Applications

This isn't just for DJs. Anyone who creates content at scale and is tired of doing it manually — this is the tool. I built it for my workflow but I made it general enough that it works for anyone who needs volume.
Music & DJs
Generate hundreds of promotional clips from a single music video, live set, or studio session. Each clip features a different section of the track, different visual moments, and branded captions ready for Reels, TikTok, and Stories. The contrast engine was designed for exactly this — Act A builds tension, Act B delivers the drop.
Content Agencies
Scale short-form production from dozens to thousands of clips per client per month. Template-based rendering ensures brand consistency across all output. Project Bins let you maintain fully isolated configurations for every client with one-click switching.
Podcasts
Extract highlight clips from long-form episodes automatically via the Longform Clips template. Pair quote-worthy moments with branded visuals and AI voiceovers. Feed the algorithm without touching a timeline.
Sports Media
Clip goal reactions, highlight plays, and post-game moments in batches. Output to every required format (vertical, square, widescreen) from a single source file in one render pass.
Comedy & Entertainment
Turn specials, sets, and sketch packages into hundreds of shareable clips. Random timestamp extraction ensures each clip feels fresh and authentic rather than a predictable highlight reel.
Real Estate & Commercial
Generate property walkthrough clips, product showcases, and testimonial snippets in bulk with consistent branding, logo watermarks, and captions locked per project.
